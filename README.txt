# Portfolio Muhammad Darrel Danadyaksa Raharja

Website portfolio pribadi sederhana dengan:
- Home
- Tentang
- Project
- Sertifikat
- Kontak
- Preview sertifikat dalam modal

## Menjalankan
Cukup buka `index.html` di browser.

## Menambah sertifikat
1. Masukkan gambar sertifikat ke `assets/certificates/`.
2. Duplikat blok `<article class="certificate-card">` pada `index.html`.
3. Ganti nama file gambar, judul, penyelenggara, dan tanggal.

Versi berikutnya bisa dikembangkan menjadi PHP + MySQL dengan login admin,
sehingga sertifikat dan project dapat ditambah melalui dashboard tanpa
mengedit HTML.
